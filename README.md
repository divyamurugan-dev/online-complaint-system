# Online Complaint Registration System

This is a simple PHP & MySQL based web application for registering and managing user complaints.

Features:
- User registration & login
- Submit complaints
- View complaint status
- Admin can solve or reject complaints

Technologies Used:
- PHP
- MySQL
- HTML, CSS

How to run:
1. Import database in phpMyAdmin
2. Place project in htdocs folder
3. Run using http://localhost/complaint_system
